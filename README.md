## Overview

A healthcare website template designed for a medical or genetic research company. It provides information about services and includes a contact section.

## Features

| ✔️ | Feature |
|---|---|
| ✅ | Informational sections detailing services |
| ✅ | Responsive design suitable for all devices |
| ✅ | Contact form or call‑to‑action buttons |


## Tech Stack

- 🛠️ HTML
- 🛠️ CSS
- 🛠️ Bootstrap
- 🛠️ JavaScript

## Installation

Follow these steps to get a local copy of the project up and running:

1. Clone the repository: `git clone https://github.com/Nischhalsubba/CareGene.git`.
2. Open the `index.html` file in a browser.
